# Portafolio Personal - Carlos Martinez

Página personal desarrollada para el primer corte de Laboratorio de Ingeniería de Software III.

El proyecto funciona como un portafolio personal en el que presento información sobre mí, mis habilidades, algunos proyectos desarrollados y medios de contacto.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Características

- Diseño responsive para computador, tablet y celular.
- Navegación entre las diferentes secciones de la página.
- Menú adaptable para dispositivos móviles.
- Sección de presentación personal.
- Sección Sobre mí.
- Sección de habilidades.
- Sección de proyectos.
- Enlaces de contacto.
